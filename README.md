# Java Math Practice

This project practices using Java variables and methods from the `Math` class.

## Exercises

- Compare Bob and Gary's salaries using `Math.max()`
- Find the lowest vehicle price using `Math.min()`
- Calculate the area of a circle with a radius of 7.25
- Find the square root of 5.0
- Calculate the distance between two points
- Find the absolute value of -3.8
- Generate a random number between 0 and 1
- Calculate the number of minutes in 24 days
- Bonus: Calculate the number of milliseconds in 24 days

## Running the Project

Compile and run the Java program to see the results printed to the console
